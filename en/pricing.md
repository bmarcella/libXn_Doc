# Pricing

**QPath / LibXN** (`@damba/libxn`) is a deterministic memory and reasoning library: exact,
traceable, hallucination-free fact memory that runs at 0 tokens with zero dependencies. It is sold
as a **single license** to the enterprise, not a per-seat subscription.

## License price

One price, perpetual enterprise license (unlimited internal use, source code included):

> **US$120,000** (about **CA$165,000**), one-time payment.

Depending on enterprise size and the scope of rights, the realistic range runs from
**US$80,000 to US$250,000** (about **CA$110,000 to CA$340,000**).

## What the license includes

- **Perpetual** right to use `@damba/libxn` across the enterprise, unlimited seats.
- **Source code** of the library, embeddable in the enterprise's products.
- Exact, deterministic retrieval, 100% recall, sub-millisecond, at 0 tokens.
- Zero dependency, isomorphic: Node, browser, Web Worker, on-premise.
- One year of updates and support included.

## Options

- **Maintenance and updates** beyond the first year: about **US$18,000 per year** (≈ CA$25,000),
  optional. The library keeps working without it; this is an update service, not a rental.
- **Integration and onboarding** (LLM, search, Postgres/pgvector persistence ports): on quote.

## Why a single price is justified

- **No token cost**: memory and reasoning run locally, the enterprise saves the LLM calls a classic
  RAG approach would spend on every query.
- **Determinism and traceability**: same data, same answers; every fact carries its provenance.
  This meets audit and compliance requirements where an LLM alone fails.
- **Reusable asset**: once acquired, the library is embedded in every enterprise product with no
  mandatory recurring fee.

Canadian dollar amounts are indicative, at the exchange rate in effect at signing.
