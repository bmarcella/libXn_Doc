# Public benchmark — the numbers, reproducible

QPath makes strong promises: exact memory, zero hallucination, zero-token reasoning, full
auditability. A public benchmark puts them to the test — **reproducible in one command**, data
generated by a seeded script, **zero network during measurement**, dated results kept forever. Two
runs of the same seed yield the same metrics, bit for bit (verified by a test).

> 🎯 **What we measure.** The three things a team building an agent tests first: does the memory
> hold when you **rephrase**? does multi-hop reasoning hold **without calling a paid model**? and
> can you **audit then retract** without leaks? We compare measurable behaviors, never
> architectures.

## Results (seed 42 · 2026-08-02)

Three corpus sizes: 1,000, 10,000 and 100,000 facts. Task 1 baseline: lexical top-k retrieval
(TF-IDF cosine, threshold 0.35, published) — a deliberate "zero network" choice: an embedding
baseline would require downloading a model; a port lets anyone plug in their own.

### Task 1 — recall under rephrasing (+ trap questions)

We store facts, then query with **verb synonyms** and **equivalent phrasings** ("lives in" /
"resides in"), plus **trap** questions about facts never stored.

| | 1k facts | 10k | 100k |
|---|---|---|---|
| QPath — exact recall | **100%** | **100%** | **100%** |
| QPath — hallucination on traps | **0%** | **0%** | **0%** |
| Baseline — exact recall | 79% | 86% | 79% |
| Baseline — hallucination on traps | 86% | 80% | 63% |
| QPath — p50 latency | < 0.1 ms | < 0.1 ms | **< 0.1 ms (flat)** |
| Baseline — p50 latency | 0.16 ms | 1.32 ms | 21.75 ms |

Two rows tell the whole story: on traps, the baseline **answers anyway** (63-86% of the time);
QPath says "I don't know". And QPath latency **does not move** when the corpus grows 100×.

### Task 2 — multi-hop reasoning at zero token

Inheritance chains of 2 to 4 hops (A is a B, B is a C, C has a property → so does A), with
**blocking negations** (the exception that stops inheritance) and traps.

| | 1k | 10k | 100k |
|---|---|---|---|
| Accuracy | **100%** | **100%** | **100%** |
| LLM tokens consumed | **0** | **0** | **0** |
| p50 latency | 0.06 ms | 0.05 ms | 0.09 ms |

The LLM baseline (the same question asked to a model with the corpus in context) plugs in through a
port: without an API key it is published as "not executed" — never invented. The cost differential
is structural: 1,000 QPath answers cost 0, at any volume.

### Task 3 — auditability and retraction

Every answer must exhibit its **provenance** (direct fact) or its **chain** (deduction). Then we
retract facts and verify they are **never** served again — while still answering "at that date, the
answer was X".

| | 1k | 10k | 100k |
|---|---|---|---|
| Traced answers | **100%** | **100%** | **100%** |
| Leaks after 100 retractions | **0** | **0** | **0** |
| Exact temporal reads | **100%** | **100%** | **100%** |

This task has no baseline: it is the differentiator. A vector index can neither cite its source
fact by fact, nor guarantee a removed memory won't resurface, nor replay yesterday's state.

## Reproduce

The harness ships with the `@damba/libxn` package:

```bash
npm run bench:public                    # 3 sizes, dated results (JSON + Markdown)
npm run bench:public -- --seed=7        # change the seed: the data changes, the guarantees don't
```

Output: the table above plus a raw JSON (metrics, seed, versions, machine specs, durations).
Machine for the published numbers: Intel Core Ultra 9 185H, Node 22 — full run in 7 s, 100,000
facts ingested in 2.3 s. Cases where the baseline wins are published in the same place as the rest.

Dated results live with the code and every new run is added without overwriting previous ones. To
reproduce the benchmark on your machine as part of an evaluation, [contact us](https://damba.io):
the full harness is provided under an evaluation license.
